## 安装前先填完这张表

| 项目 | 需要记录的信息 |
| --- | --- |
| 固件 | OpenWrt 或衍生固件的准确版本 |
| 架构 | 路由器 CPU 与固件目标架构 |
| 包管理 | 固件使用的包管理方式和匹配的插件格式 |
| 存储 | 安装及运行所需空间是否足够 |
| 原配置 | 可恢复的固件和网络配置备份 |
| 管理入口 | 路由器地址、管理方式与备用连接方式 |

不要根据“同型号路由器安装成功”就忽略固件差异。不同固件可能包含不同依赖与预装网络组件。

## 核对原始安装说明

从 vernesong/OpenClash 进入当前发行说明。先核对依赖，再选择与环境匹配的安装包。网络上的旧命令可能针对另一版固件，不宜直接整段执行。

## 缩小第一次修改的范围

第一次安装先确认插件能正常显示并读取配置，不同时改动全部网关、DHCP、DNS 和防火墙。保留当前能进入管理页面的路径，避免在远程连接不稳定时进行大范围网络调整。

## 安装后记录结果

记录插件版本、所用配置与启动日志。先从一台测试终端验证，再逐步确认其他设备。如果出现异常，按预先保存的设置回退，而不是临时搜索一组未经核对的“万能修复命令”。

## 来源与适用范围

[开发者项目或文档](https://github.com/vernesong/OpenClash) 用于核对软件身份与功能边界。本文的排查顺序为编辑整理，不是实机测试记录；具体菜单、支持格式和系统要求请结合所用版本确认。
